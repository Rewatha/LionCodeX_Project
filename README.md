# LionCodeX – E-Commerce Website

A team-based e-commerce website developed as part of a university project for SealTech Engineering (PVT) LTD.

## Project Overview
LionCodeX is a responsive e-commerce web application designed to showcase products, manage customers, and support basic admin operations. The project focuses on clean UI, usability, and structured front-end development.

## Features
- Product listing and display
- Customer management
- Admin dashboard
- Responsive design
- User-friendly interface
